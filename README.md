My To-Do List Application

A simple desktop To-Do List application developed using C programming and Windows API.

Features

Add new tasks
View multiple tasks
Delete selected tasks
Mark tasks as completed
Save and load tasks automatically using a text file
Technologies Used

C Programming
Windows API (Win32)
GCC Compiler
Visual Studio Code
How to Run

Compile the program:

gcc todo.c -o todo.exe -mwindows -luser32 -lgdi32

Run the application:

.\todo.exe

Project Description

This project was developed to practise C programming and understand GUI development, event handling and file handling.
